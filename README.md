# Codebase-Linker

A single-file, interactive web utility tool for dynamically mapping complex source code file relationships.


![HTML](https://img.shields.io/badge/HTML-d4692e?logo=html5&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)
![](https://img.shields.io/badge/File_System_Access-API-b9d9ec?logo=files&logoColor=b9d9ec)

### What it does
- A locally-run, single-file web utility utilizing the File System Access API to dynamically parse directories and visualize file dependencies within a software codebase.


### Intended use
- To map out software architecture, enabling developers and AI tools to understand complex project structures and navigate file relationships efficiently.
